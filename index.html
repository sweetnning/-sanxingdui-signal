01 · Foundation

01品牌基础层：从"遗址"到"超级 IP"的定位跃迁

品牌核心定位、视觉识别系统与建筑即品牌的战略构建

核心定位要素

维度内容关键特征
文化根基长江文明之源，距今 5000-3000 年，20 世纪人类最伟大考古发现之一世界级
品牌气质神秘、神奇、神圣 —— 古蜀文明最突出的风格特征差异化
品牌愿景"世界的三星堆" —— 从区域性遗址跃升为世界级文化符号国际化
核心挑战无文字记载，无法依托历史叙事，必须通过现代流行表达重新演绎独特短板

视觉识别系统构成

要素设计策略具体表现
标志提取青铜面具核心特征几何化粗眉大眼、阔口高鼻融入几何化倒梯形，侧放面具形象；启功手书字体；英文名融入图形
色彩青铜色为主调，营造神秘典雅气质展陈主色调青铜色 + 黑金色版面；新馆米色艺术混凝土 + 古铜色金属板 + 深灰色地面
建筑符号老馆"谜"叙事 vs 新馆"眼"符号老馆：螺旋曲线"入谜-点谜-述谜-解谜"；新馆："堆列三星，古蜀之眼"覆土堆体

三星堆博物馆的标志抽取了青铜面具粗眉大眼、阔口高鼻的造型特征，融合于一个几何化的倒梯形之中，使标志整体视觉感受又合乎一个侧放着的面具形象，造型独特、表情神秘。

阶段特征代表产品/模式战略意义

03品牌产品层：文创产业链与商业化路径

"一个超级品牌、二大平台、三种模式、四个方向、五大系列"的产业化体系

产业化发展模式

维度具体内容战略价值
一个超级品牌"世界的三星堆"统一品牌认知，降低传播成本
二大平台线下文创馆 + 线上旗舰店（官微/淘宝/有赞）全渠道覆盖，场景化消费
三种模式自主开发、授权联营、品牌授权灵活应对不同品类与资源禀赋
四个方向文创产品、影视文学、IP 授权、空间打造多元化收入结构，抗风险能力
五大系列神系 / 潮玩 / 科技 / 飞翔 / 数字三星堆覆盖不同人群与消费场景

爆款产品解析

产品创新策略市场表现核心洞察
"祈福神官"盲盒5 个代表性文物形象拟人化呈现，众筹开发模式2020 中国旅游商品大赛银奖，销售额近 500 万元文物拟人化降低认知门槛，众筹验证市场需求
"面具冰淇淋""青铜味""出土味"双口味，反差感文案五一假期销量 2 万+ 支，总销量超 5 万支反差感营销 + 社交货币属性，激发打卡传播
"考古盲盒"玩家用小工具挖掘"惊喜"，仪式感设计2021 年推出后持续迭代，成为长线爆款体验感设计超越产品本身，创造参与式消费
"堆堆堆"咖啡/茶饮书法手写"堆"字为 LOGO，诙谐文案新馆文化商业顾问联合设计，独立品牌运营子品牌独立运营，避免主品牌稀释

跨界联名授权体系

品类合作品牌合作形式策略要点
餐饮麦当劳、书亦烧仙草"巴适得板"风味汉堡、主题餐厅地域文化融合，场景沉浸式体验
酒类剑南春"青铜纪"系列文创酒，三度合作 + 数字藏品文化关联度高，品牌强强联手
服饰/运动鸿星尔克等联名服饰、运动鞋国潮趋势借势，年轻化触达
游戏/数字腾讯《王者荣耀》《乱世王者》《原神》角色皮肤、场景植入、数字藏品亿级用户触达，Z 世代渗透
非遗工艺建水紫陶《大梦三星》《快客杯》等联名作品传统文化互鉴，提升品牌厚度
联名策略原则：并非为经济效益主导，而是为品牌和文化宣推服务；只选择与文化有关联度、品牌较强、受众面较广的品牌合作，避免过度授权损害品牌价值。

07 · Transfer

07对科技馆品牌设计的启示与借鉴

从三星堆到科技馆：可迁移的方法论与关键成功要素

方法论迁移对照

维度三星堆实践科技馆借鉴路径
品牌定位从"遗址"到"世界的三星堆"从"科普场所"到"未来科技文化符号"
视觉系统提取文物核心特征（面具、眼睛）几何化提取科技核心符号（DNA、芯片、光子、宇宙）抽象化
IP 矩阵主 IP + 7 个子 IP主馆 IP + 子 IP（儿童科技、AI 实验室、太空主题）
内容叙事用现代文艺弥补"缺文少字"用故事化、游戏化弥补"专业门槛高"
产品体系盲盒、食品、饮品、潮玩全品类科技玩具、STEM 教具、科幻周边、实验套装
空间体验"入谜-点谜-述谜-解谜"叙事动线"好奇-探索-发现-创造"体验动线
数字融合VR/AR + AI 修复 + 智慧管理数字孪生 + AI 交互 + 沉浸式剧场
授权管理准入标准 + 负面清单 + 分成模式科技品牌联名 + 教育 IP 授权 + 企业合作标准

六大关键成功要素

01 符号的强识别性

青铜面具几何化标志成为超级符号，一眼可识别

02 "守正出奇"的创作原则

学术严谨打底，表现形式大胆创新

03 从"做形象"到"做内容"

不是设计一个 Logo，而是构建叙事生态

04 IP 矩阵而非单点突破

7 个子 IP 覆盖不同人群与场景，互为支撑

05 建筑即媒介

新馆本身就是最大的品牌表达，空间即内容

06 知识产权先行

1270+ 商标、980+ 版权，品牌护城河从第一天开始

品牌不是设计的终点，而是文化价值与现代生活连接的起点。

从 0 到 1 的关键，在于找到那个既能承载机构使命、又能激发公众情感共鸣的核心符号，并围绕它构建一个可生长、可迭代、可商业化的品牌生态系统。
